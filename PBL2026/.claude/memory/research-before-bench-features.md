Owner, 2026-10-08: *"first you have to research what will be needed when a teacher is teaching
with an interactive animation bench. this will help us know what features to implement in the
bench … then you list the capabilities that we need so that i will give the data chatgpt to render
the ui."* It stopped a prototype that was being built straight from one card's production brief.

**Why:** features chosen from one card's brief fit that card and miss the teaching job. The owner
designs the UI from a capability list (renders made in ChatGPT), and the bench is built to the renders.

**How to apply:** for a new bench: research (learning science + existing tools + ExSight's rules)
→ capability list grouped by surface and view, with control states and sample data → owner's
renders → build. Keep the research in `bench-work/research/`. Related:
[[three-d-bench-is-modelling]], [[bench-quality-bar]].
