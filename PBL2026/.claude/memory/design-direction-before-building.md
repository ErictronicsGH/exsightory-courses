Owner, 2026-10-08, when I started building a 2D neon eye-to-brain animation straight from their
request: *"so always before you do any of these things you need to tell me so i give you the design
direction"*.

**Why:** the owner has a clear visual taste (they had just said the D1·030 previews were "classical
textbook" and asked for a realistic, neon-glow 2D animation). Building first wastes work when the
direction is theirs to set.

**How to apply:** for any visual piece (a bench prototype, an animation library, a new drawing style, a
re-render), first send a short design plan: the scenes and views, the look (palette, line style, glow),
what moves and what stays still, labels and frame, and any conflict with the quality bar or design rules.
Then wait for their direction before writing code or assets. Specs written for later building still
follow [[render-visual-milestones]]; this rule is about deciding the look before making it. Related:
[[bench-quality-bar]], [[design-rules-from-the-start]].
