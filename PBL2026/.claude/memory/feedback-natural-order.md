Course content must follow a natural, organic order: each lesson flows into the next, following
the physical path of the measurement. The user flagged that the eye/sensory-system intro should flow
naturally into sensors, then accepted either order ("sensors could follow measurements") as long as
the order is natural. We settled on cold open → measurand/uncertainty → sensing, with the eye →
sense organ → sensor link made explicit at the hand-off.

**Why:** the user teaches by organic progression, not topic lists.
**How to apply:** every module opens by saying where on the path it is and ends with a transition
into the next stage; analogies (eye, sugar → calibration) get called back where they pay off.
