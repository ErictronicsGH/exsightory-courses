Owner, 2026-10-10, after card 7's stills: *"remember: Realism >= 95%, scientific facts 100% accuracy, mathematical facts
100% accuracy, visualization and intuition 100%, consistency and coherence, professional design. all these should be
treated as first class requirements in the animation"*.

**Why:** the owner kept asking for review passes after each build (card 5, card 6: "correctness, consistency, reality,
physics, mathematics"); these are no longer review items but requirements every build must meet before it is sent.

**How to apply:** treat all six as gates for every still, motion and film, not as polish:
1. **Realism ≥ 95 %**: real objects drawn as they are (proportions, materials, markings), real behaviour including the
   non-ideal ([[bench-quality-bar]], [[reference-designs-set-the-look]]).
2. **Science 100 %**: every mechanism physically right; a stand-in effect that is too small or design-dependent to be
   honest is replaced and reported, never exaggerated (card 7's 3b: mains pickup → stem conduction).
3. **Maths 100 %**: every number recomputed (Node) from the drawing's own geometry; text, panels and displays agree to
   the last digit ([[drawing-and-numbers-agree]]).
4. **Visualization and intuition 100 %**: compared things on one scale, one ball = one reading, motion that shows cause →
   effect in the order it happens ([[visual-accuracy-same-scale]], [[animation-follows-the-flow]]).
5. **Consistency and coherence**: the same values, colours, letters, units and names across views, blocks, cards and
   languages; nothing contradicts an earlier card.
6. **Professional design**: nothing overlaps or runs off its panel, type fits (EN and FR), a clean hierarchy, the course's
   look.
Check all six (and say so) before sending anything to the owner. The checklist: `.claude/standards/six-gates.md`; the rule is also in CLAUDE.md, so every session loads it.
