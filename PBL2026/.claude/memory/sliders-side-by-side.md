Owner, 2026-10-20, on the U016 preview: *"the sliders can be [moved] to side on same row each with its label on top and
short name in parenthesis"*.

**Why:** a stack of label-left sliders took a lot of height under the plot and named the controls only by symbol.

**How to apply:** in every preview page and every spec's control layout, put a group's sliders in one row (a grid that
wraps to one per line on a phone), each with its label above it in words with the symbol in parentheses, e.g.
"Source resistance (R_s)", "Acquisition window (t_acq)", "Resolution (N, bits)", and the live value at the right of the
label. Specs that describe controls say so, so the Benches lane builds it that way. Related: [[tidy-bench-bar]],
[[render-what-you-are-doing]].
