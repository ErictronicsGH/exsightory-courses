Owner, 2026-10-11: *"although in the room we call it electronics bench, in the studio application we call it the
breadboard bench as the actual electronics bench in the studio app is the simulation schematic environment"*.

**Why:** two names for one bench. Mixing them up would point specs, captions or requests at the wrong product bench.

**How to apply:**
- In the 3D lab (signs, tour captions, station id `electronics`) it stays **"Electronics Bench"**.
- In anything about Studio (specs, capability lists, M49, requests to ExSight, course PLAN cues) it is the
  **Breadboard Bench**.
- **"Electronics Bench" in a Studio context** means the schematic simulation environment (see
  [[electronics-bench-in-development]]).
- When writing for the owner about the lab's bench, say both once: *"the Electronics Bench (Studio's Breadboard Bench)"*.
