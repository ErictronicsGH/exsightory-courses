# Requests to ExSight

What this course's bench specs need from the product (InsightDemo), gathered in one place so they can be
raised together. This project does not edit InsightDemo; each request names the spec that needs it and
what happens on Saturday without it. Newest first within each kind.

**Since 2026-10-20 a new request is a crossing, not a row here** (`CLAUDE.md`, *Talking to the Benches lane*). The
benches are ExSightory's Benches lane's (Electronics, Draw, Equation, Plot, Figure, Animation, Breadboard), so a row
below that is still *to raise* and is a bench's goes to Benches as a crossing from `pbl2026` when the course needs it,
and its row then names the crossing. A row that is Studio's or Core's goes to the owner, who routes it. "InsightDemo"
below means `C:\ExSightory`.
