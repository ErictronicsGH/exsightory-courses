# Bench work

Everything the benches will need for this course, written now so each activity can be built straight
from its file when its bench is ready (owner, 2026-10-08). The benches themselves, and the libraries built for this
course, live in exsight-benches (`C:\ExSightory\src\exsight-benches`) since 2026-10-13: the Benches lane builds there, this
project specifies here and asks for each build by a crossing (`CLAUDE.md`, *Talking to the Benches lane*).

| Folder | Holds |
|---|---|
| `specs/` | One spec per bench activity (a card that shows a bench): the bench (the platform) and the library it loads, in the shape of `.claude/standards/bench-spec-template.md` |
| `research/`, `prototypes/`, `libraries/`, `components/` | **Moved to exsight-benches** (2026-10-13). What is left in them here is evidence only: `shots/`, films, frames, contact sheets and archives, at their old paths. Where each source went: `.claude/memory/benches-live-in-exsight-benches.md` |
| `previews/` | Previews of what the specs draw, from their own numbers (`make_preview.py` → one page per unit: `u010-u011-preview.html`, `u012-preview.html`, `u013-preview.html`, `u015-preview.html`): rendered for the owner at each visual milestone |
| `requests-to-exsight.md` | What the specs need from the product (InsightDemo), with what stands in until each lands |
| `animation-bench-capabilities.md` | The Animation Bench's capability list, for the UI renders (U001): paste §0, §3a, then one screen from §6 at a time |
| `research/01-learning-science.md` | 45 evidence-based requirements for teaching with animation (2D/3D) |
| `research/02-product-survey.md` | What ~25 products give teachers; 36 ideas; 14 gaps |
| `research/03-exsight-constraints.md` | ExSight's building blocks and binding rules for the bench; this course's animation needs |
| `research/04-eye-anatomy-optics-sources.md` | The eye's anatomy, optics and pathway numbers, each checked against a source (U003) |
| `prototypes/eye-to-brain/` | The Animation Bench prototype for D1·010 card 3 (three.js 0.185.1); its README says how to open and drive it |

Design rules for every bench surface: `.claude/standards/bench-design-rules.md`.

Every spec must pass `.claude/standards/bench-quality-bar.md`. Tracking is in `.claude/tracking/`
(one unit per module, U010–U034).
