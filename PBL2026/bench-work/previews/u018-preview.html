Card 1 · A code is a ratio to the reference


EquationThe PLAN's Equation, code = (Vin / Vref)·2N, rearranged to Vin = code·Vref / 2N and graphed as the code against Vin. The demo is 12 bits, 3.3 V, and 1.65 V gives 2048. Zoom near 1.65 V shows the steps the straight line hides. The course's converter keeps the whole part of the code (it truncates), so the graph is a staircase under the ideal line (D5).


code = ⌊ (Vin / Vref) · 2N ⌋   ⇔   Vin ≈ code · Vref / 2N












Card 2 · The code alone means nothing


Equationnumeric ×2The numeric's reveal: card 1's Equation with the code held at 2047 and the reference switched between 3.3 V and 1.1 V. The graph is read backwards: from the code across to the line, then down to the voltage. The same fraction, 2047/4096 = 0.4998, of whatever the reference is.



Reference




Answers 1.649 V (± 0.002) and 0.550 V (± 0.001), as the PLAN gives them. On a truncating converter the code 2047 stands for a band one step wide: 1.6492 to 1.6500 V on 3.3 V, and 0.5497 to 0.5500 V on 1.1 V. The PLAN's answers are the bottom of each band, rounded: 1.649 sits 0.19 mV below the band, and 0.550 is its open top. Both tolerance windows contain the whole band, so every exact answer is accepted (corrected 2026-10-20, from card 2's spec).





Card 3 · Reference error is measurement error


EquationpoeThe poe's reveal: 12 bits, 1.65 V in, and the reference (the supply rail) slid from 3.30 V to 3.20 V. The line steepens. The input's marker climbs from 2048 to 2112 (+3.1 %), and firmware that still multiplies by 3.3 V reports 1.70 V. The 3.30 V line stays dashed for comparison.







Checked: 1.65/3.20 × 4096 = 2112 exactly (2112/2048 = 1.031); 2112 × 3.3/4096 = 1.7016 V. The FAULT (3.3 V in firmware, 3.28 V delivered) is 3.3/3.28 − 1 = +0.61 %. A reference 1 % high gives readings 0.99 % low. Both 2048 and 2112 sit exactly on a code edge. The bench computes them exactly (in floating point, 1.65/3.2 × 4096 comes out as 2111.9999…, which truncates to 2111), and the spec says so.





Card 4 · VDD: the default, and usually the worst


Animation, by BenchespollThe PLAN's widget is an Electronics Bench one and stays deferred while that bench is being built. The card still gets its demonstration. The proposal is an Animation Bench demonstration that Benches would build on a crossing (D2). The board's 3.3 V rail, behind its source resistance, feeds the MCU's own load and is the ADC's reference. A separate 1.65 V reference drives the input. The load steps from 10 to 200 mA, and a PCB trace can be switched into the rail. The schematic below previews the numbers the demonstration must show.



MCU loadRail




The source resistance is 50 mΩ, as the PLAN gives it: 190 mA × 50 mΩ = 9.5 mV ("about 10 mV"), and the code goes from 2048 to 2054 ("about 6"). F1: the course's own supply (the sw3005) holds its setpoint to 0.1 % + 10 mV, about 2.7 mΩ, so it cannot be the 50 mΩ. Here the 50 mΩ is the rail as the MCU pin sees it: the regulator plus its wiring. The trace (D3) is the PLAN's 0.5 mm part in 1 oz (35 µm) copper, 0.98 mΩ per mm at 20 °C. 50 mm of it adds 49 mΩ, so the drop becomes 18.8 mV and the code climbs 12.





Card 5 · Ratiometric: let the error cancel (the centrepiece)


PlotEquationpoeThe PLAN's Plot: the code against the rail Vdd from 3.0 to 3.6 V for two inputs. One is a fixed 1.65 V measured against the rail (amber: it falls). The other is the 10 k NTC (B = 3950 K) under a 10 kΩ resistor, powered from that same rail (teal: flat). Sweep the rail, then move the temperature: the flat line moves with the temperature and ignores the rail. The Equation below shows the rail cancelling.









code = ( Vdd · k ) / Vdd · 2N = k · 2N,   k = RT / (RT + RF)


Checked: 1.65/3.0 × 4096 = 2252.8 → 2252 on the course's truncating converter (F4, applied: the Flow now says 2252); 1.65/3.6 × 4096 = 1877.3 → 1877. At 25 °C, k = 0.5 → 2048. The temperature runs 0–50 °C: 3156 at 0 °C, 1081 at 50 °C (RT = 10 kΩ·eB(1/T − 1/298.15 K)). The NTC is the bottom of the divider, so the line falls as the temperature rises.
