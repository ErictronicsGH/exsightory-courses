STATIC CHARACTERISTICS OF MEASUREMENT SYSTEMS
- In some measurement systems the quantity to be measured changes so slowly that it is only necessary to know the static characteristics of the sensors.
- Nevertheless, the static characteristics also influence the dynamic behaviour of the sensor -- that is, its behaviour when the measure quantity changes with time.
- Unfortunately, ,the mathematical description of the joint consideration of static and dynamic characteristics is complex. As a result, static and dynamic behavior are studied separately.

- The concepts used to describe static characteristics are not exclusive to sensor. They are common to all measurement instruments.

- Accuracy, Precision and Sensitivity
    - It is a measure of the closeness of the measured results to the measured quantity.
    -  A true, exact or ideal value is the value that would be obtained by a perfect measurement.
    - Exact values are by nature indeterminate.
    - A conventional true value of a quantity is the value attributed to a particular quantity and accepted sometime by convention as having an uncertainty appropriate for the given purpose.
    - Sensor accuracy is determined through static calibration.
    - Static calibration consists of keeping constant all sensor inputs, except the one to be studied.
    - This input is changed slowly, thus taking successive constant values along the measurement range and recording the results.
    - Their plot against input values form the calibration curve
