# The Part 3 exam

One paper, sat on your phone, on everything the supply has asked of you. Every
question is from the course's bank, pinned to the version this exam was set
against, so the paper a student sat can still be printed after the bank moves on.

objective: Heat, smoothing, regulation and fault protection, one question each
timeLimitMinutes: 40

backNavigation: false
