# The size ceiling

A drawing at exactly the size a wall paints inside its budget: five thousand
segments, in a thousand short strokes, built up in ten bands. It is generated
(`apps/desktop/tools/ceiling-drawing.mjs`) so the load and the first paint can
be measured at the ceiling (performance budgets §4c).
