# Curves drawn from their equations

A function shape holds its equation rather than its points: the curve is fitted
from the equation every time it is drawn, so it is exact wherever it is shown.
These were made with `insight-draw shape`. The meter's hairspring, in the first
lesson, is one too: a polar spiral, `r = 0.1 θ`.

## An oscillation dying away

```drawing
title: A damped oscillation
src: shared/drawings/damped-oscillation.benchdrawing
alt: A horizontal time axis. Two dashed amber curves, mirror images of each other, fall from the top and bottom towards the axis as time goes on, and between them a teal wave swings from one to the other, each swing smaller than the last.
caption: Each swing is the same fraction of the one before, so the envelope is an exponential.
```

## The mean value of half a sine wave

```drawing
title: The mean of half a sine wave
src: shared/drawings/half-wave-mean.benchdrawing
alt: One hump of a sine wave standing on a time axis, the area under it shaded teal, and a dashed amber rectangle over the same width whose height is about two thirds of the hump's, labelled mean.
caption: The rectangle and the hump have the same area, so the rectangle's height is the mean value, 2/π of the peak.
```
