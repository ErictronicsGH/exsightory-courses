# Voltage across a part

A reading of voltage across a part is only as good as the way it was taken. Note the range, the connection and the moment, then write the number down before you interpret it (0).

## Voltage across a part, step 1

A reading of voltage across a part is only as good as the way it was taken. Note the range, the connection and the moment, then write the number down before you interpret it (1).

A reading of the step is only as good as the way it was taken. Note the range, the connection and the moment, then write the number down before you interpret it (1).
